# Changelog

## v0.2.0
- Download files directly from Cloudflare R2 (no server bandwidth used)
- System tray — app hides to tray on close, keeps running in background
- Right-click context menu: download, rename, delete
- Create new folders inline
- Delete confirmation dialog
- Transfer queue shows upload vs download icon

## v0.1.0
- Login with existing workin account (JWT stored in OS keychain)
- Browse files and folders
- Upload any size file directly to Cloudflare R2 (multipart, 4 parallel chunks, retry)
- Live transfer progress with speed and ETA
- Drag-and-drop upload
